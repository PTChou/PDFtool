將此應用打包成 Android APK

本網頁程式完全採離線單檔案架構，可透過官方推薦的 Capacitor 工具，只需 3 條指令即可包裝成正式的 Android APK 檔案！

# 1. 建立專案資料夾並下載此 index.html

mkdir pdf-apk && cd pdf-apk

# 2. 初始化 Capacitor 容器

npm init -y

npm install @capacitor/core @capacitor/cli @capacitor/android

npx cap init "PDF Protector" com.pdf.protector --web-dir .

# 3. 新增 Android 平台並生成 APK

npx cap add android

npx cap open android
